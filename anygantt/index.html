Features

Everything you need in a record-page timeline

A native Lightning Web Component with no iframes, no external services and no data leaving your org.

Bars on a timeline

Records show up as colour-coded bars between their start and end dates. Bars that run past the edge of the visible range get a faded clip so it's obvious they continue.

Any object, any date fields

Standard or custom objects. Map any lookup and any date or datetime fields from a point-and-click configuration modal.

Day, week and month zoom

Switch between day (2 weeks), week (6 weeks) and month (6 months). Page forward and back, or jump straight to today.

Admin-friendly setup

Pick child objects, date fields, display fields, colours and row grouping from a modal. Config is stored as custom metadata.

Permission-aware

Respects object and field-level security. Only users with the AnyGantt+ Admin perm set can change the config.

Colour by picklist

Map picklist values to bar colours (status, priority, team). Click a bar to view or edit the record. Click an empty date to create one.

Setup

Up and running in minutes

Three steps from install to a working Gantt chart. The setup guide has the details.

1. Install the package

Install AnyGantt+ from the AppExchange and assign the AnyGantt+ Admin perm set to whoever will set up timelines.

2. Add the component

Open any record page in Lightning App Builder and drag AnyGantt+ onto the layout.

3. Configure and go

Click Configure Gantt, pick a child object, choose your date fields, map display fields and colours. Hit save and the timeline is live.
