Shared platform

What every component has in common

Built on the same architecture, following the same principles.

Any object, any record page

No hardcoded objects or fields. Configure the child object, lookup and display fields from a point-and-click modal.

Permission-aware

Respects object and field-level security. All queries run in user mode. Admin actions need a dedicated permission set.

Click-to-configure

No code, no metadata files, no deployments. Admins set up each view from a configuration modal on the record page.

Native Lightning

No iframes, no external services, no data leaving your org. Runs entirely inside Salesforce as a managed package.

Free forever

The full suite will be free on the AppExchange. No trial, no feature gates, no surprise invoices.
