Features

Everything you need in a record-page Kanban

A native Lightning Web Component with no iframes, no external services and no data leaving your org.

Drag-and-drop cards

Drag records between columns to update the picklist value instantly. No page refresh, no extra clicks.

Any object, any picklist

Standard or custom objects. Map any lookup and any picklist field from a point-and-click configuration modal.

Admin-friendly setup

Configure child objects, column fields, card display fields and colours from a guided modal. Stored as custom metadata.

Permission-aware

Respects object and field-level security. Only users with the AnyKanban+ Admin permission set can configure boards.

Inline record actions

Click a card to view, open or edit the record without leaving the page. Create new records directly into any column.

Compact & swimlane views

Toggle between a compact card view and a swimlane layout grouped by a second field. Fits any workflow.

Setup

Up and running in minutes

Three steps from install to a working Kanban board on any record page. The setup guide walks through each one in detail.

1. Install the package

Install AnyKanban+ from the AppExchange and assign the AnyKanban+ Admin permission set to your board administrators.

2. Add the component

Open any record page in Lightning App Builder and drag AnyKanban+ onto the layout.

3. Configure and go

Click Configure Board, pick a child object, choose a picklist field for columns, and map display fields. Save, and the board is live for everyone on that page.
